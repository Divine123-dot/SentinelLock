# SentinelLock (IntruderWatch-Linux)

## Project Overview

SentinelLock is a Python-based Linux security monitoring project
designed to detect repeated authentication failures, record
security events, and generate incident alerts.

The project is being developed incrementally as a learning and
portfolio project.

## Objectives

- Implement authentication verification.
- Detect repeated failed authentication attempts.
- Record and analyze security events.
- Send security notifications through authenticated email.
- Retrieve approximate public-IP geolocation information.
- Explore permission-controlled webcam evidence capture.
- Monitor Ubuntu authentication events.
- Document testing and security limitations.

## Technology Stack

- Ubuntu Linux
- Python 3
- Git and GitHub
- requests
- python-dotenv
- OpenCV

## Security and Privacy

Initial development uses simulated authentication events.

Real-system monitoring will be introduced after the simulator
has been tested.

Webcam functionality will be permission-controlled.
Credentials and private incident evidence must not be published.

## Current Limitations

SentinelLock is a work in progress. It is not yet a complete
anti-theft system and should not be relied upon as the sole
protection for a device.
